## 1. Model count

- **37 custom entity types** under `web/modules/custom/*/src/Entity/*.php` — **36 `@ContentEntityType`** + **1 `@ConfigEntityType`** (`application_statuses`).
  `Evidence:` [web/modules/custom/](../../intake/current-solution/_source/patronus/web/modules/custom/); full list in [db-inventory.md §2](../evidence/db-inventory.md).
- **Storage:** Drupal 10 Entity/Field API on **MariaDB**; per-entity SQL tables are **framework-generated** from `baseFieldDefinitions()` — only **2** custom `hook_schema()` tables exist (`login_history`, `maib_example`). Column DDL is convention, not source-declared.
  `Evidence:` [db-inventory.md §1, §4](../evidence/db-inventory.md).
- **Drupal core entities** (not custom types, but carry the CMS config fields): `node` bundles `blog`/`page`/`page_cz`/`success_page`/`form_page`, `user`, `taxonomy_term` (10 vocabularies), `media`, `block_content`.
  `Evidence:` [config/](../../intake/current-solution/_source/patronus/config/) `node.type.*`, `field.field.*`, `taxonomy.vocabulary.*`.

## 5. Signals for later agents

- **The status model is the spine.** `application_workflow` (~66 states / ~40 transitions, content_moderation) is the canonical current-state status enum bound to `application` — reconcile with [intake/statuses/](../../intake/statuses/) during status reconstruction.
  `Evidence:` [workflows.workflow.application_workflow.yml](../../intake/current-solution/_source/patronus/config/workflows.workflow.application_workflow.yml).
- **Enums live in PHP, not config.** Most `list_*` allowed-values are code-defined in `baseFieldDefinitions()` (aprofile, transaction), not in `field.storage.*` — extract from entity classes, not config. `Evidence:` [db-inventory.md §5](../evidence/db-inventory.md).
- **No DB-level FKs.** All cross-entity links are Drupal soft `entity_reference` (target_id), so referential integrity is application-enforced, not DB-enforced. Treat relations as logical. `Evidence:` [db-constraints-and-validation.md](../evidence/db-constraints-and-validation.md).
- **Conflicts to resolve in 02:** several entities have annotation-vs-config translation mismatches and dangling `entity_keys` (see [db-inventory.md §6](../evidence/db-inventory.md)) — carried as `Conflict — requires clarification`.
