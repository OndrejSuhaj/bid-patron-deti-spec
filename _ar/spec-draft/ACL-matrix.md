# ACL Layer Matrix / Map

Registry of the ACL (access-control) layer for the current Patronus platform. Owning layer for the
actor/role × resource × action × scope model. Generated by AR:ACLMatrixSynthesizer.

- **Ground truth:** `config/user.role.*.yml` (15 roles), each module `*.permissions.yml`, and route
  `_permission` / `_access` / `_custom_access` requirements in `*.routing.yml`.
- **Status:** all docs `draft`. Classifications are per-row inside each doc.
- **Scope vocabulary:** `own` (ownership-enforced in code) · `global` (all records, no country
  filter) · `platform` (site-wide admin) · `public` (session-tier / REST allow-list).
