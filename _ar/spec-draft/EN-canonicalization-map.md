# EN Canonicalization Map

Tracks, per entity, which source artifacts were used to canonicalize the EN document and what was
removed/preserved. Refreshed in place per entity on each ENCanonicalizer run — do not duplicate rows
for an entity already listed; update its row instead.

One row per entity. "Source Artifacts" = the prior implementation-heavy EN draft plus the AR
artifacts consulted for reference-resolution (BR rules, UC triggers, DOMAIN-kernel invariants,
glossary, sibling EN docs for relationship cross-check). "Removed Technical Traces" summarizes the
implementation-leakage categories stripped from the body. "Preserved Lifecycle Facts" summarizes the
canonical domain facts kept (purpose, states, UC-triggered transitions, invariants cited to BR,
relationships). "Notes" records ambiguities carried forward as Open Questions rather than resolved.
