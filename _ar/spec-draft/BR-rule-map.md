# BR Rule Map (Patronus)

> Generated by **AR:BRExtractor** · 2026-07-02 · deduplicated canonical rule catalog
>
> One row per rule section of each canonical `BR-*` document in `_ar/spec-draft/BR/`. Columns:
> **BR File** · **Rule Section(s)** · **Source Artifacts** (INV/FN/UC/EN/MSG/HS/§ provenance) ·
> **Ownership** (which layer/fact the rule governs, single-source) · **Notes** (merge / dedup /
> cross-BR delegation). Every `## Purpose` and `## Non-Goals` section is present per document and is
> not listed as a rule row. All rules are **current-state**; where a rule records that a guarantee is
> *not enforced today*, that is a faithful current-state rule, not a target proposal.
>
> Structure: **19 domain-scoped BR files** (no prior BR layout existed → deterministic domain scope
> created). `SYSTEM`-affecting cross-cutting rules are placed in the BR that owns the domain concept;
> BR-OperationalAlerting owns no domain entity by design.
