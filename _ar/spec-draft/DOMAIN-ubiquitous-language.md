> Generated by **AR:DomainKernelSynthesizer** on **2026-07-02**, from the reconstructed
> **EN** (entities), **UC** (use-cases), **SRV** (services/bounded contexts) and **Flow**

> system, CZ/RO/MD).
>
> **Purpose.** This document fixes the shared vocabulary of the current system so its behavior can be
> read without paging through source. Each canonical term ties to its owning **EN** entity (single
> owning layer) and, where applicable, the **UC** that exercises it. Per cross-layer discipline, this
> document does **not** restate the full EN definition — it references EN by `doc_id` and gives a
> one-line working definition.
>
> **Evidence policy.** Every hard claim traces to EN / UC / Flow evidence; no rule is invented. Where
> evidence is thin the term is flagged (Hypothesis / open question) inline. No code-level tokens
> (file/class/method/table names) are used as canonical vocabulary — code identifiers appear only as
> non-canonical *synonyms* to help readers cross-map to source.
>
> **Language governance.** Project source language is **Czech**; the **English canonical** term is
> primary; **CZ/RO/MD** wordings are recorded as *synonyms/variants*, not separate canonical rows. This
> complements — it does **not** replace — the AR glossary workflow
> (`_ar/repo-map/glossary-master.csv` → `glossary.md`); on divergence the glossary workflow governs.

## 2. Overloaded / ambiguous terms
