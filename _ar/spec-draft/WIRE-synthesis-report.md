## 1. Active rules / template used

- `tooling/docs/rules-WIRE.md` — governing rules for this layer. Hard rule 1 enforced throughout:
  `realizes_uc` is **mandatory** (at least one UC); a screen without a use case is invalid and must
  **not** get a WIRE file.
- `tooling/templates/template-WIRE.md` — section skeleton used for every written WIRE doc: Purpose,
  Layout Zones (ASCII sketch), Components Used, Interactions, States (default/empty/loading/error),
  Validation Surfaces, Data Bindings, Conditional Visibility, Accessibility Notes, Open Questions.
- `tooling/docs/cross-layer-discipline.md` — single-source-of-truth discipline: WIRE references
  `doc_id`s from EN/UC/BR rather than restating their content; no BR, COMP, ACL, or IA content was
  inlined by any WIRE doc in this pass.
- COMP layer does not exist yet at this pipeline stage — all visual elements across all 22 written
  WIRE docs are flagged `inline` (total 227 inline component instances across screens; see §6).
- ACL layer does not exist yet — role-gating claims are cited from UC/BR prose only, never asserted
  as an ACL fact.

## 6. Inline components — candidates for COMP promotion

The COMP layer does not exist yet; every visual element across all 22 WIRE docs is flagged `inline`.
Total inline component instances: **227** (sum of per-screen counts in the coverage table). The
following recur across 3+ screens and are the strongest promotion candidates for
**AR:COMPSynthesizer**:

- **Primary/secondary CTA button** (e.g. "Pokračovat", "Odeslat", "Uložit změny", "Přispět") —
  appears on nearly every screen with a form (S002, S006–S012, S021).

  the entire application wizard.

  S007, S008e) with no consistent validation backing (see §5) but consistent visual/interaction shape.

  dropzones), S005 (Evidence-Pending, by analogy).
