# FN Capability Map — Patronus current-state reconstruction (bid-patron-deti)

> Generated by **AR:FNSynthesizer** on **2026-07-02**.
> The **FN** layer replaces the *publish* role previously carried by the **SRV** and **FLOW**
> artifacts: SRV/FLOW remain reconstruction evidence, FN is the publishable functional-capability view.
> Every capability below is **evidence-grounded** in already-reconstructed AR artifacts (UC/EN/SRV/FLOW/ARCH)
> and contains **no code-level detail** (no file/class/method/route/queue names). Rows describe what the
> system is internally *capable of* today (current state only — not `it-zadani` target intent).
>
> Clustering rule applied: FN does **not** mirror SRV or FLOW one-to-one. Adapter families are grouped
> into one capability (payment gateways, registry/identity adapters, reconciliation sources, ops-alerting
> transports). Named-integration literals (ComGate, Netopia, MAIB, Mautic, ARES, MVČR, Moneta, OneDrive,
> Elasticsearch, Slack, Telegram, Facebook, GTM, WhoisXML, Nager.Date) and status-vocabulary literals
> (PAID, to_check, scoring_ok, campaign_uncompleted, PENDING/AUTHORIZED/CANCELLED/REFUNDED) are allowed.
>
> Related ARCH for every row: **ARCH0001** (Application Overview) + **ARCH0002** (Context Interaction Map).
> Downstream ES/MSG/BR layers are not yet built; see FN-synthesis-report.md §6.

## Legend

- **Source UC / EN** — canonical use-case / entity `doc_id`s the capability is grounded in and references (never restates).
- **Source SRV/FLOW** — reconstruction evidence (SRVxxxx target services, FLWxxxx mined dossiers, FLxxx un-mined flow ids). Evidence only; FN does not mirror it 1:1.
- **Integrations** — external systems the capability touches (named-integration literals allowed). "None directly" means the external boundary is isolated in a sibling FN.
- **Notes** — clustering rationale, current-state limitations/hazards, evidence gaps (Partial / Hypothesis / un-mined / Dormant / Plan-Not-Implemented), and RefIntegrity follow-ups.
- Related ARCH for all rows: **ARCH0001** + **ARCH0002** (see header).
