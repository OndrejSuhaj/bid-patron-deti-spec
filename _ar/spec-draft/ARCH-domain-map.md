## Reading conventions

- **One domain = one ARCH doc.** ARCH0003..ARCH0012 are a *navigation* layer only; they carry no
  use-case flow, entity-model detail, rule content, or implementation/framework detail — those live
  in the referenced EN/UC/FN/ES/MSG/BR docs and are cited by `doc_id`.
- **Shared aggregates / shared concerns are cross-referenced, never duplicated.** AG7 Party is shared
  by C7 (ARCH0009) and C9 (ARCH0011); transition-legality is shared by C1 (ARCH0003) and the merged
  C11 fabric (ARCH0012). Each such fact keeps a single owning domain doc and is referenced from the other.
- **"(none)" entries are information, not omissions.** A `(none)` ES/MSG/BR cell records that the
  domain owns no artifact of that layer and reaches it only via a sibling domain — kept per the
  skip-empty-sections exception for absence-that-is-information (cross-layer discipline §5).
- **Coverage:** every EN0001–EN0032, UC0001–UC0022, FN0001–FN0026, ES0001–ES0016, MSG0001–MSG0030,
  and all 19 authored BR files are reachable from ≥1 domain above (no orphans). See
  [`ARCH-domain-assembly-report.md`](ARCH-domain-assembly-report.md) §5.
