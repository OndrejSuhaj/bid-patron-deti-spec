## 3. Dependency notes (allowed direction after restructure)

- **Processors → Orchestrators/Domain** (never embed domain): SRV0006, SRV0016, scheduled-publish, CSV export, recurring/reconciliation crons trigger domain/orchestrator services.
- **Orchestrators → Domain + Adapters**: SRV0002 coordinates SRV0003/SRV0011/SRV0013; SRV0013 coordinates email/Mautic adapters.
- **Domain → Adapters (via ports, never direct vendor)**: SRV0007→SRV0008 (payment port); SRV0003→SRV0004 (verification); SRV0009 domain→IMAP/Moneta adapters.
- **Domain → Domain (explicit ports)**: SRV0001↔SRV0005 (application/campaign state sync); SRV0003→SRV0012 (blacklist write) must become an explicit port, not a direct field write.
- **Everyone → Messaging (SRV0013)** and **→ Observability (SRV0018)** as cross-cutting.
