## 1. Discipline / ownership table used

Restatement rule (§4 of cross-layer-discipline.md): a block of another layer's owned content **>50
characters** appearing verbatim or near-verbatim in a **non-owning** layer is a restatement violation
→ replace with a `doc_id` reference. Allowed (not violations): the `references:` frontmatter list; a
≤50-char orientation summary next to a `doc_id`; a bare folder/layer pointer; status-vocabulary
values; named integrations; the `doc_id` citations themselves.

Ownership applied (each layer owns; all others reference by `doc_id`):

| Layer | Owns (canonical content) |
|-------|--------------------------|
| EN | entity semantics, lifecycle, states, attributes, entity-local invariants, relationships |
| BR | business rules, cross-entity constraints, domain invariants, domain policies |
| UC | use-case behavior, numbered flows, triggers, pre/postconditions, lifecycle changes |
| FN | internal functional capabilities, responsibilities |
| ARCH | system structure, components, interaction model, scope |
| ES | external systems, integration boundaries, data exchange |
| MSG | transactional messages (trigger, recipients, content) |

Invariant-ownership guide used throughout: a **domain policy** ("raised may not exceed target",
"donation inadmissible against a funded Campaign") is **BR**-owned; an **entity lifecycle/state**
("in-progress → active → completed") is **EN**-owned. Where an EN or ARCH doc legitimately owns the
*existence* of a structure (e.g. Transaction's parent/child self-reference), that existence fact was
kept and only the *rule* it carries was delegated to BR by citation.

## 5. Unresolved references recorded as Open Questions

No *unresolved* references (every cited owner `doc_id` resolves within `_ar/spec-draft/`). Two
non-blocking residual notes are recorded for downstream awareness:

1. **UC-layer reference convention (layer-wide, not a single-doc defect).** UC0006 and its sibling UC
   docs carry **no** `references:` YAML frontmatter; they convey `doc_id` references inline via a
   **Traceability** section. To preserve each doc's structure (§4/§8), owner citations for UC0017 and
   UC0006 were added to Traceability rather than injecting a foreign frontmatter block. **Open
   Question:** whether the UC layer should standardize on a `references:` frontmatter — a layer-wide
   convention decision outside this de-dup pass; hand to RefIntegrityValidator.

2. **UC0006 `accepts any caller` (public-exposure facet).** The removed clause's "accepts any caller"
   nuance is not restated verbatim in BR-PaymentGatewayCallbacks § Confirmation authentication; per
   BR-rule-map that public-exposure facet is cross-referenced to BR-AccessControlAndRoles §
   Authentication. The replacement citation points at the shared-secret/signature/replay facet fully
   owned by BR-PaymentGatewayCallbacks; no meaning was lost (AF1's own outcome already states no side
   effects run), and the public-exposure nuance now lives only in the BR layer, as intended.

3. **FN0006 Purpose scope phrase.** The Purpose line retains a ≤50-char scope phrase
   ("auto-complete or uncomplete on the deadline") with no normative SHALL / target-threshold
   semantics — treated as allowed orientation, not a restatement. Flagged only if a stricter reading
   later requires a `doc_id` anchor on scope-orientation phrasing.
