# API Layer Contract Map

Registry of the API (system-facing HTTP contract) layer for the current Patronus platform. Owning
layer for REST-resource-plugin request/response shapes, auth mode, and per-endpoint hazards.
Generated by AR:APIContractSynthesizer.

- **Ground truth:** module `src/Plugin/rest/resource/**/*.php` REST resource plugin classes, matching
  `config/rest.resource.*.yml` config entities (auth mode, enabled/disabled status, methods, formats),
  module `*.routing.yml` (HTML routes excluded from this layer — see `Contract type` below), module
  `*.permissions.yml`, and `config/user.role.*.yml` (15 roles) for the calling-permission cross-check.
- **Status:** all 18 docs `draft`. Endpoint counts are per-document endpoint groups (version variants
  of the same operation folded into one group where behavior is materially identical; kept separate
  where a version delta changes the contract).
- **Contract type vocabulary:** `rest-public` (anonymous-reachable per role config, donor/visitor
  facing), `rest-internal` (session-authenticated, back-office or system-internal, no anonymous
  grant confirmed — though several still show an anonymous-grant hazard, see synthesis report),
  `webhook` (inbound, third-party-triggered, not first-party-frontend-driven).
- **Scope:** system-facing HTTP/REST contracts only. Drupal HTML admin routes and internal
  service-to-service calls (Views, Twig, Form API) are explicitly out of scope for this layer and are
  noted as Open Items inside the relevant doc where a CRUD surface exists only as an HTML form.

## Known gaps / not yet contracted

- **`patron_devel`** — excluded, dev-only tooling module (see synthesis report).
- **Payment gateway callback modules** (`comgate`, `maib`, `netopia`, `monetaapi`) — inbound
  gateway-callback routes are referenced as hazards inside API0004's Open Items but were **not**
  ground-truthed as their own API docs in this pass; already flagged at the ACL layer (`ACL0005`,
  gap G-05: payment-gateway callback routes effectively public). Recommended as a follow-up
  APIContractSynthesizer pass — see synthesis report Recommended Next Step.
- **`contract` module's HTML routes** (list/create/checking/send_to_fundraiser/e-sign) — internal
  Drupal form routes, not REST; out of scope for this layer, flagged inside API0015 Open Items.
- **`contact` module's real Contact (EN0006) CRUD** — HTML admin routes only, not REST; out of scope,
  flagged inside API0016 Open Items.
- **Blog (EN0024) authoring** — no UC/FN currently owns this as an orchestrated flow; API0009 is
  anchored directly to EN0024 pending a future UC pass.
- **Feedback (EN0021) authoring/consumption** — same gap pattern as Blog; API0008 anchored to EN0021 +
  FN0006 pending a future UC pass.
- **Supplier/Partner CRUD** — HTML-admin-only (Drupal generic entity forms); API0010/API0011 document
  only the public read surface.
