   structured reference data + conditional form behaviour with **no EN (no "gift category" concept in
   glossary) and no UC field-model**. Directly shapes what an applicant can request and how it is
   priced. *Evidence:* screencapture-patrondeti-cz-zadost-formular-2026-07-04-13_20_39.png,
   screencapture-patrondeti-cz-zadost-formular-2026-07-04-13_20_57.png.

   capability — the primary donor funnel — with **no owning UC** (UC0011 is admin lifecycle). Filters
   *Zbývající částka / Samoživitelé / Filtrovat podle krajů / Brzy skončí* and the collection-account
   story-card type need a read/browse UC. *Evidence:* screencapture-patrondeti-cz-2026-07-04-13_15_49.png,
