> back-office screen (`/admin/**`) was captured, so the large administrative surface behind the

> completeness of the system.
>
> Merge rule: multiple scroll/interaction shots of the same `urlPath` are one row. `test.png`
> (a 1-concept junk capture, `screenName: "Test"`) is excluded as non-evidence.
> Two files are e-mails (Gmail render), listed separately as they map to the MSG layer, not a screen.
>
> Coverage vocabulary: **Covered** = screen's primary behaviour maps cleanly to an existing UC/MSG;
> **Partial** = mapped UC exists but the screen surfaces behaviour/fields/states the UC does not
> capture; **Missing** = no UC/MSG owns this screen's behaviour; **Uncertain** = mapping plausible but
> not confirmable from evidence, or the capture itself is ambiguous/incomplete.
